💰 AI Personal Finance Dashboard
📌 Overview

The AI Personal Finance Dashboard is a data analytics and machine learning project that helps users analyze their financial transactions and predict future expenses.

It provides insights into spending patterns, category-wise expenses, and estimated future costs using historical data.

🚀 Features
📊 Expense & Income Analysis
📅 Date-wise and Monthly Trends
🧾 Category-wise Spending Breakdown
🔮 Expense Prediction (AI-based)
📉 Savings Calculation
🌐 Interactive Dashboard (Streamlit UI)
🧠 How AI is Used

This project uses a Machine Learning Regression Model (Linear Regression) to predict future expenses.

Input Features:
Day of transaction
Category of expense
Output:
Predicted expense amount (₹)

The model learns patterns from historical data and provides estimated values based on user input.

🛠️ Tech Stack
Python
Pandas (Data Processing)
NumPy
Scikit-learn (Machine Learning)
Matplotlib / Seaborn (Visualization)
Streamlit (Frontend Dashboard)
